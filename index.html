ℹ️ Tentang Proyek

Monitoring Suhu Rak Server adalah sistem monitoring & kontrol suhu rak server berbasis ESP32-S3 dengan MQTT + Firebase Realtime Database.

🎯 Fitur Utama

  • Monitoring real-time DHT22 + 2× DS18B20
  • Interval simpan Firebase dapat diubah dari web
  • Setpoint editable melalui MQTT
  • Log permanen Firebase
  • Export Excel per tanggal dan seluruh data
  • Grafik trend dan mode malam

🔧 Hardware

ESP32-S3DHT222× DS18B203× RelayLCD I2C2× PeltierFan

⏱️ Interval

  • Baca sensor: 2 detik
  • Kirim MQTT: 5 detik
  • Simpan Firebase: default 10 detik, dapat diubah dari web
