ℹ️ Tentang Proyek

Monitoring Suhu Rak Server adalah sistem monitoring & kontrol suhu rak server berbasis ESP32-S3 dengan MQTT + Firebase Realtime Database. Dikembangkan di Politeknik Negeri Indramayu.

🎯 Fitur Utama

  • ESP32 kirim data langsung ke Firebase (24/7)
  • Interval simpan Firebase editable dari web (2s - 5m)
  • Tombol Refresh manual (bukan auto-refresh)
  • Monitoring real-time DHT22 + 2× DS18B20
  • Setpoint editable (tersimpan di EEPROM)
  • Log permanen Firebase + export Excel per kolom
  • Grafik trend interaktif + mode malam/siang

🔧 Hardware

ESP32-S3 DHT22 2× DS18B20 3× Relay LCD I2C 2× Peltier Fan

⏱️ Interval Sistem

  • Baca sensor: 2 detik
  • Kirim MQTT: 5 detik
  • Simpan Firebase: default 10 detik (bisa diubah dari web)
